## Contributing and reporting issues

The issue tracker is currently disabled. Use a documentation pull request to
suggest corrections or flag missing setup and feature documentation. When
sharing UX feedback with the maintainer, include:

- The screen or flow you were using and the steps to reproduce the problem.
- What you expected to happen and what actually happened.
- The app version and device or operating system, if available.

Do not include passwords, account tokens, or personal information in reports
or screenshots.

For documentation improvements, fork the repository, make a focused change,
and open a pull request. Application changes require the app source code,
which is not present here.
